
# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I.

## Integrantes
- Eloisa Costa Guedes
- Nome do segundo integrante (se houver)

## Como jogar

Digite uma letra por vez e clique no botão Tentar.

O objetivo é descobrir a palavra secreta antes que as seis tentativas acabem.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Escolha aleatória de palavras.
- Categorias.
- Dicas para descobrir as palavras.
- Controle de tentativas.
- Identificação de letras corretas e incorretas.
- Bloqueio de letras repetidas.
- Mensagens de vitória e derrota.
- Reinício da partida.
- Utilização da tecla Enter.
